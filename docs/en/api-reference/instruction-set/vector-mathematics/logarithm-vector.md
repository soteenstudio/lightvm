# Vector Logarithms

These instructions evaluate logarithms element by element.

| Opcode | Arguments | Operands (stack) | Description |
| --- | --- | --- | --- |
| `lnv` | type | values | Replaces one numeric array with an equal-length array of natural logarithms; type must be `hlf`, `flt`, or `dbl`. |
| `log2v` | type | values | Replaces one numeric array with an equal-length array of base-2 logarithms; type must be `hlf`, `flt`, or `dbl`. |
| `log10v` | type | values | Replaces one numeric array with an equal-length array of base-10 logarithms; type must be `hlf`, `flt`, or `dbl`. |
