| :--- | :--- | :--- | :--- |
| `sin` | type | val | Sine or Cosine trigonometric operation |
| `cos` | type | val | |
| `tan` | type | val | Tangent trigonometric operation |
| `sinh` | type | val | Hyperbolic Sine or Cosine operation |
| `cosh` | type | val | |
| `tanh` | type | val | Hyperbolic Tangent operation |
| `asin` | type | val | Arcsine or Arccosine trigonometric operation |
| `acos` | type | val | |
| `atan` | type | val | Arctangent trigonometric operation |
| `atan2` | type | val1, val2 | Two-argument Arctangent operation |
