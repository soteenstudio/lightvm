# Aritmatika Dasar
Instruksi-instruksi ini menangani perhitungan matematika standar, skala dasar, dan modifikasi variabel secara langsung.

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| :--- | :--- | :--- | :--- |
| `add` / `sub` | tipe | val1, val2 | Penjumlahan atau Pengurangan |
| `mul` / `div` | tipe | val1, val2 | Perkalian atau Pembagian |
| `mod` | tipe | val1, val2 | Modulo (Sisa Bagi) |
| `neg` | tipe | val | Negasi (-5 ke 5, atau sebaliknya) |
| `inc` / `dec` | nama, tipe | - | Langsung menambah/mengurangi isi variabel |
| `pow` | tipe | val1, val2 | Operasi perpangkatan umum (x^y) |
| `powi` | tipe | val1, val2 | Pangkat dengan eksponen bilangan bulat |
| `powf` | tipe | val1, val2 | Pangkat dengan eksponen pecahan (floating-point) |
