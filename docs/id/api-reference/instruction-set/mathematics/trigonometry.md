# Trigonometri

Instruksi ini mengevaluasi fungsi trigonometri, invers, dan hiperbolik skalar.

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| --- | --- | --- | --- |
| `sin` / `cos` / `tan` | tipe | nilai | Mengganti satu operan dengan sinus, kosinus, atau tangennya; tipe harus `hlf`, `flt`, atau `dbl`. |
| `asin` / `acos` / `atan` | tipe | nilai | Mengganti satu operan dengan invers sinus, kosinus, atau tangennya; tipe harus `hlf`, `flt`, atau `dbl`. |
| `atan2` | tipe | y, x | Mengganti dua operan dengan `atan2(y, x)`; `x` berada di atas, dan tipe harus `hlf`, `flt`, atau `dbl`. |
| `sinh` / `cosh` / `tanh` | tipe | nilai | Mengganti satu operan dengan sinus, kosinus, atau tangen hiperboliknya; tipe harus `hlf`, `flt`, atau `dbl`. |
| `asinh` / `acosh` / `atanh` | tipe | nilai | Mengganti satu operan dengan invers sinus, kosinus, atau tangen hiperboliknya; tipe harus `hlf`, `flt`, atau `dbl`. |
