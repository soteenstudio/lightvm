# Eksponensiasi Vektor
Instruksi ini mengevaluasi fungsi eksponensial natural secara element-wise pada sebuah vektor (array).

Instruksi ini menerima direktif tipe float `hlf`, `flt`, dan `dbl`. Instruksi menggunakan satu operan array dan menggantinya dengan array yang berisi hasil element-wise dalam tipe yang dipilih.

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| :--- | :--- | :--- | :--- |
| `expv` | type | arr | Memangkatkan e dengan setiap elemen array sebagai eksponen |
