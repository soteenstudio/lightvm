# Akar

Instruksi ini mengevaluasi akar kuadrat dan akar pangkat tiga skalar.

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| --- | --- | --- | --- |
| `sqrt` | tipe | nilai | Mengganti satu operan dengan akar kuadratnya; tipe harus `hlf`, `flt`, atau `dbl`. |
| `cbrt` | tipe | nilai | Mengganti satu operan dengan akar pangkat tiganya; tipe harus `hlf`, `flt`, atau `dbl`. |
