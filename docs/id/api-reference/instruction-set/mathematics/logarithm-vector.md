# Logaritma Vektor
Instruksi-instruksi ini mengevaluasi fungsi logaritma secara element-wise pada sebuah vektor (array).

Instruksi ini menerima direktif tipe float `hlf`, `flt`, dan `dbl`. Setiap instruksi menggunakan satu operan array dan menggantinya dengan array yang berisi hasil element-wise dalam tipe yang dipilih.

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| :--- | :--- | :--- | :--- |
| `lnv` | type | arr | Mengevaluasi logaritma natural untuk setiap elemen array |
| `log2v` | type | arr | Mengevaluasi logaritma basis 2 untuk setiap elemen array |
| `log10v` | type | arr | Mengevaluasi logaritma basis 10 untuk setiap elemen array |
