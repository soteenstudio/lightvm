# Akar Vektor
Instruksi-instruksi ini mengevaluasi fungsi akar secara element-wise pada sebuah vektor (array).

Instruksi ini menerima direktif tipe float `hlf`, `flt`, dan `dbl`. Setiap instruksi menggunakan satu operan array dan menggantinya dengan array yang berisi hasil element-wise dalam tipe yang dipilih.

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| :--- | :--- | :--- | :--- |
| `sqrtv` | type | arr | Mengevaluasi akar kuadrat untuk setiap elemen array |
| `cbrtv` | type | arr | Mengevaluasi akar pangkat tiga untuk setiap elemen array |
