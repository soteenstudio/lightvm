# Trigonometri Vektor
Instruksi-instruksi ini mengevaluasi fungsi trigonometri secara element-wise pada vektor (array).

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| :--- | :--- | :--- | :--- |
| `sinv` | type | arr | Mengevaluasi fungsi sinus untuk setiap elemen array |
| `cosv` | type | arr | Mengevaluasi fungsi kosinus untuk setiap elemen array |
| `tanv` | type | arr | Mengevaluasi fungsi tangen untuk setiap elemen array |
| `asinv` | type | arr | Mengevaluasi fungsi invers sinus untuk setiap elemen array |
| `acosv` | type | arr | Mengevaluasi fungsi invers kosinus untuk setiap elemen array |
| `atanv` | type | arr | Mengevaluasi fungsi invers tangen untuk setiap elemen array |
| `atan2v` | type | arrX, arrY | Mengevaluasi fungsi invers tangen dua argumen untuk setiap pasangan elemen array |
| `sinhv` | type | arr | Mengevaluasi fungsi sinus hiperbolik untuk setiap elemen array |
| `coshv` | type | arr | Mengevaluasi fungsi kosinus hiperbolik untuk setiap elemen array |
| `tanhv` | type | arr | Mengevaluasi fungsi tangen hiperbolik untuk setiap elemen array |
| `asinhv` | type | arr | Mengevaluasi fungsi invers sinus hiperbolik untuk setiap elemen array |
| `acoshv` | type | arr | Mengevaluasi fungsi invers kosinus hiperbolik untuk setiap elemen array |
| `atanhv` | type | arr | Mengevaluasi fungsi invers tangen hiperbolik untuk setiap elemen array |
