# Operasi Vektor
Instruksi-instruksi ini melakukan aritmatika elemen-per-elemen pada vektor (array) dan menghitung hasil kali vektor yang digunakan dalam aljabar linear.

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| :--- | :--- | :--- | :--- |
| `addv` / `subv` | tipe | arr1, arr2 | Penjumlahan atau Pengurangan elemen-per-elemen dua vektor |
| `mulv` / `divv` | tipe | arr1, arr2 | Perkalian atau Pembagian elemen-per-elemen dua vektor |
| `modv` | tipe | arr1, arr2 | Modulo (Sisa Bagi) elemen-per-elemen dua vektor |
| `negv` | tipe | arr | Negasi elemen-per-elemen satu vektor |
| `dot` | tipe | arr1, arr2 | Hasil kali titik (dot product) dua vektor (menghasilkan skalar) |
| `cross` | tipe | arr1, arr2 | Hasil kali silang (cross product) dua vektor 3-elemen (menghasilkan vektor 3-elemen) |
