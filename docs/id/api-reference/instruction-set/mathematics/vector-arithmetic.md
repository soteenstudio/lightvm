# Aritmatika Vektor
Instruksi-instruksi ini melakukan operasi aritmatika element-wise pada vektor (array).

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| :--- | :--- | :--- | :--- |
| `addv` / `subv` | type | arr1, arr2 | Penjumlahan atau Pengurangan element-wise dari dua vektor |
| `mulv` / `divv` | type | arr1, arr2 | Perkalian atau Pembagian element-wise dari dua vektor |
| `modv` | type | arr1, arr2 | Modulo (Sisa Bagi) element-wise dari dua vektor |
| `negv` | type | arr | Negasi element-wise dari sebuah vektor |
