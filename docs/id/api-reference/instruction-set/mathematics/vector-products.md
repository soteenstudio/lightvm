# Hasil Kali Vektor
Instruksi-instruksi ini menghitung hasil kali vektor yang digunakan dalam aljabar linear.

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| :--- | :--- | :--- | :--- |
| `dot` | type | arr1, arr2 | Hasil kali titik (dot product) dari dua vektor (mengembalikan skalar) |
| `cross` | type | arr1, arr2 | Hasil kali silang (cross product) dari dua vektor 3 elemen (mengembalikan vektor 3 elemen) |
