# Matematika Lanjutan
Instruksi-instruksi ini menjalankan fungsi matematika kompleks termasuk trigonometri, hiperbolik, logaritma, dan operasi akar.

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| :--- | :--- | :--- | :--- |
| `sin` / `cos` | tipe | val1, val2 | Operasi trigonometri Sinus atau Kosinus |
| `tan` | tipe | val1, val2 | Operasi trigonometri Tangen |
| `sinh` / `cosh` | tipe | val | Operasi Sinus atau Kosinus Hiperbolik |
| `tanh` | tipe | val | Operasi Tangen Hiperbolik |
| `asin` / `acos` | tipe | val | Operasi Arcsin atau Arccos |
| `atan` | tipe | val | Operasi Arctangen |
| `atan2` | tipe | val1, val2 | Operasi Arctangen dua argumen |
| `asinh` / `acosh` | tipe | val | Operasi Invers Sinus atau Kosinus Hiperbolik |
| `atanh` | tipe | val | Operasi Invers Tangen Hiperbolik |
| `sqrt` / `cbrt` | tipe | val | Operasi Akar Kuadrat atau Akar Pangkat Tiga |
| `ln` | tipe | val | Operasi Logaritma Natural dengan basis konstanta e |
| `log2` / `log10` | tipe | val | Operasi Logaritma dengan opsi basis 2 atau 10 |
| `exp` | tipe | val | Operasi fungsi Eksponensial Natural berbasis konstanta e |
