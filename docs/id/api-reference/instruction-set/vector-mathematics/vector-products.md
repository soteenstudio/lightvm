# Hasil Kali Vektor

Instruksi ini menghitung dot product dan cross product dari array numerik.

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| --- | --- | --- | --- |
| `dot` | tipe | kiri, kanan | Mengganti dua array numerik dengan panjang sama dengan satu skalar: jumlah `left[i] * right[i]` dalam tipe yang dipilih. |
| `cross` | tipe | kiri, kanan | Mengganti dua array numerik yang masing-masing tepat tiga elemen dengan array cross product tiga elemen, dengan mempertahankan urutan operan. |
