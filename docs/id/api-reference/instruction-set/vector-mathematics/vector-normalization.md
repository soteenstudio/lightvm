# Normalisasi Vektor

Instruksi `normalize` menskalakan vektor floating-point menjadi panjang satu unit.

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| --- | --- | --- | --- |
| `normalize` | tipe | nilai | Mengganti satu array floating-point dengan vektor satuan berpanjang sama dalam tipe yang dipilih; tipe harus `hlf`, `flt`, atau `dbl`, dan vektor nol menghasilkan vektor nol dengan panjang yang sama. |
