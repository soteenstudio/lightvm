# Operasi Bitwise Vektor

Instruksi ini menggeser atau merotasi elemen bilangan bulat yang bersesuaian dalam dua array.

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| --- | --- | --- | --- |
| `shlv` | tipe | nilai, jumlah | Mengganti dua array dengan panjang sama dengan pergeseran kiri element-wise; array teratas menyediakan jumlah pergeseran, dan tipe harus `sht`, `int`, `lng`, atau `oct`. |
| `shrv` | tipe | nilai, jumlah | Mengganti dua array dengan panjang sama dengan pergeseran kanan element-wise; array teratas menyediakan jumlah pergeseran, dan tipe harus `sht`, `int`, `lng`, atau `oct`. |
| `rolv` | tipe | nilai, jumlah | Mengganti dua array dengan panjang sama dengan rotasi kiri element-wise; array teratas menyediakan jumlah rotasi, dan tipe harus `sht`, `int`, `lng`, atau `oct`. |
| `rorv` | tipe | nilai, jumlah | Mengganti dua array dengan panjang sama dengan rotasi kanan element-wise; array teratas menyediakan jumlah rotasi, dan tipe harus `sht`, `int`, `lng`, atau `oct`. |
