# Logaritma Vektor

Instruksi ini mengevaluasi logaritma secara element-wise.

| Kode Operasi | Argumen | Operan (stack) | Deskripsi |
| --- | --- | --- | --- |
| `lnv` | tipe | nilai | Mengganti satu array numerik dengan array logaritma alami berpanjang sama; tipe harus `hlf`, `flt`, atau `dbl`. |
| `log2v` | tipe | nilai | Mengganti satu array numerik dengan array logaritma basis 2 berpanjang sama; tipe harus `hlf`, `flt`, atau `dbl`. |
| `log10v` | tipe | nilai | Mengganti satu array numerik dengan array logaritma basis 10 berpanjang sama; tipe harus `hlf`, `flt`, atau `dbl`. |
